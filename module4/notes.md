# Learning the Basics of Git and GitHub  

In this module, I learned the fundamentals of Git, a version control system, and how it differs from GitHub, a platform for hosting and collaborating on Git repositories.  

## Key Concepts Learned:  
- **Git Basics**:  
    - Git is a tool for tracking changes in code and managing versions locally.  
    - Commands like `git init`, `git add`, `git commit`, and `git status` help manage changes.  

- **GitHub**:  
    - GitHub is a cloud-based platform where Git repositories can be hosted and shared.  
    - It enables collaboration through pull requests, issues, and code reviews.  

## Commands Practiced:  
- **Commit**: Used `git commit` to save changes locally with descriptive messages.  
- **Push and Pull**: Learned to use `git push` to upload changes to GitHub and `git pull` to fetch updates from the remote repository.  
- **Branching**: Created new branches with `git branch` and switched between them using `git checkout`. This allowed me to work on features independently without affecting the main codebase.  

This experience helped me understand how Git and GitHub work together to streamline version control and collaboration.
